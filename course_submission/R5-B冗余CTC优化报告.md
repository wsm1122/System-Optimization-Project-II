运行：`r5/results/ctc_B_20261122T075117Z_59e285f8`。真实 GPU/完整 dev 正确性执行 PASS；性能结论单独判定。

## 1. 改动与保护

R4 和官方代码均未修改。只在隔离运行时把原始 topk→view→tolist→scores 四条语句放进 `if knn_args.build_index or not knn_args.knn`，正常检索分支只保留最终融合假设。原方法、生成方法、code.diff 随本 run 保存；独立开关默认 OFF。

保护清单 185 个文件 SHA-256 全部保持。模型/字典/库/索引哈希前后匹配。固定 k=1024、nprobe=32、lambda=0.5、temperature=1、skip_blank=true；原始聚合，不混入 R4 GPU分配优化。

## 2. 诊断与小规模正确性

真实 dev CTC 张量上冗余块局部均值 0.058510 ms，72 次，六条音频；为独立同步局部实验，不是端到端分项比例。

CPU 分支回归覆盖 build_index/knn 四种组合及 blank、重复 token，假设与 scores 一致；这不是 GPU 建库或所有其他解码分支的真实集成验证。六条真实 dev 的 features、Encoder、CTC、query、IDs、距离、labels、检索/融合概率、scores、文本比较通过；IDs/labels严格一致，浮点容差 rtol=1e-5、atol=1e-6，最大误差和张量摘要见 correctness.json。
